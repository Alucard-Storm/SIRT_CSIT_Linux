# Experiment 1: Study of Basic & User Status Unix/Linux Commands

## Basic Commands:
1. ls - List directory contents
   Usage: ls [options] [directory]
   Example: ls -l (detailed listing)
           ls -a (show hidden files)

2. pwd - Print Working Directory
   Usage: pwd
   Shows current directory location

3. cd - Change Directory
   Usage: cd [directory]
   Example: cd /home
           cd .. (go up one level)

4. mkdir - Make Directory
   Usage: mkdir [directory_name]
   Creates new directory

## User Status Commands:
1. whoami - Display current user
   Usage: whoami

2. who - Show who is logged in
   Usage: who
   Shows all logged-in users

3. id - Print user and group information
   Usage: id [username]

4. groups - Print group memberships
   Usage: groups [username]

5. finger - User information lookup
   Usage: finger [username]

## File Management Commands:
1. touch - Create empty file
2. cp - Copy files
3. mv - Move/rename files
4. rm - Remove files

## Process Commands:
1. ps - Show process status
2. top - Display running processes
3. kill - Terminate processes
