## Configuration File Directories

Linux stores configuration details in text files, predominantly inside `/etc/`:
- **`/etc/passwd`** contains: `username:password_flag:UID:GID:Full_Name:Home_Dir:Login_Shell`.
- **`/etc/hosts`** routes network targets locally before checking DNS servers.
- **`.bashrc`** executes every time you open a new interactive terminal, setting up paths, shell styling, and shortcut commands.
